# Ejecución

Carpeta para almacenar ejecuciones, logs, scripts y resultados de ejecución de proyectos y ejercicios contenidos en este repositorio.

Añade aquí archivos relacionados con la ejecución: scripts, salidas (logs), capturas, y notas sobre cómo ejecutar cada proyecto.

Sugerencias:
- Usa subcarpetas por proyecto o por fecha.
- Incluye un archivo README en subcarpetas con pasos para reproducir la ejecución.
