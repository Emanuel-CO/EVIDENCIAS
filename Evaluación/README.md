# Evaluación

Carpeta para almacenar evaluaciones, rúbricas, resultados, retroalimentación y evidencias de evaluación de los proyectos y ejercicios.

Usa esta carpeta para:
- Guardar rúbricas y criterios de evaluación.
- Subir resultados y observaciones de evaluaciones.
- Incluir evidencias que apoyen la evaluación (capturas, informes, archivos de test).

Sugerencias:
- Organizar por proyecto o por fecha en subcarpetas: `proyecto-x/`, `2026-09/`.
- Añadir un README en cada subcarpeta con resumen de la evaluación y conclusiones.
