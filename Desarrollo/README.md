# Desarrollo

Carpeta para almacenar el código fuente, proyectos en desarrollo, ejercicios y recursos relacionados con la programación y el desarrollo de software.

Incluye aquí:
- Proyectos organizados por carpeta.
- Documentación mínima para ejecutar cada proyecto (README en cada subcarpeta).
- Archivos de configuración (por ejemplo, .env.example, Dockerfile, docker-compose.yml).

Sugerencias:
- Usar una estructura clara por proyecto: `proyecto-x/src`, `proyecto-x/tests`, `proyecto-x/docs`.
- Añadir un README.md por proyecto con pasos para ejecutar y pruebas.
